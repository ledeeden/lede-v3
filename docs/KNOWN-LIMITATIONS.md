# 已知限制与未覆盖能力

这些边界在交付时主动记录，不能用“38项测试通过”替代实际验收。

## 需要用户环境补验

- 没有真实模型Key，未测试真实服务商的工具调用稳定性、推理质量、长任务成本、限流和不同模型的协议变体。只实现Chat Completions兼容协议，不是所有API通用。
- 本轮已在 macOS / Node 25.9 与原生 Chrome 验证；Mac 休眠唤醒、打包分发和厂商网络仍未验收。
- 本轮原生浏览器已覆盖本地 HTTP 与生产 CSP，旧 bridge 记录只代表当时环境。未修改任何浏览器策略。
- 未做大规模负载、长时间浸泡测试或独立安全审计。

## 当前实现范围

- 不是DSH完整SDK：没有Cordis动态插件树、原生Agent Teams、PTC、ACP、DSH所有Provider与模型缓存细节。
- 没有MCP客户端/服务端或外部CLI Agent适配。本地执行者都使用本应用内核和工具接口。
- Skills当前是Bot配置引用的知识URI与指令材料，不是脚本Skill包自动发现/安装系统。
- 不包含互联网通用搜索引擎。web.fetch读取已知公开URL；知识search只查本地资料。批量研究需提供来源或后续增加搜索适配。
- 文本导入支持 md/txt/json/csv/html；PDF.js 提取 PDF 文字，图片识别和音视频转写已接兼容服务，但尚无真实服务商质量验收。DOCX/XLSX/PPTX 已支持内容提取与阅读，ZIP 支持目录；旧二进制 Office 与 EPUB 无专门阅读器。
- 原件上传上限 100 MB，视觉识别上限 20 MB；未实现大文件分片上传、自动视频转码或全量媒体同步。转写提供方可能有更低的大小/格式限制。
- 未实现多人权限、账号登录、跨设备同步、共享链接、消息推送、定时任务、插件市场和自动升级。

## 可靠性边界

- 重启不盲目重放正在执行的外部工具。unknown需要检查；等待关系可恢复不等于外部进程可恢复到同一指令。
- Message request_id去重不等于所有外部调用exactly-once。换request_id或换语义任务会重新执行。
- 相同发件人的未读消息没有自动合并；没有移植DS-Bot全部群聊/迟到回执策略。
- 上下文压缩是模型生成摘要，可能遗漏信息；保留原始日志和原文URI，但并非无损记忆。极长单条输入/异常大工具定义仍可能超过提供方窗口。
- 业务任务done只强制证据字段与依赖完成，不自动判定报告和证据是否正确。

## 数据、检索、插件

- UI bootstrap目前加载完整资源集合；列表接口支持分页，但前端未全面虚拟分页。适用于当前本地工作空间，不宣称百万级资料性能。
- 向量检索为本地精确扫描，无ANN；重排使用配置的聊天模型（非专用 cross-encoder 服务）；更新后通过后台补齐向量。未配置向量时是显式FTS模式。
- 执行成员研究自动生成 L0/L1；普通手工知识和集合仍按需生成。失败摘要可手动重试，不自动循环重试。长资料只在预算内采样，概览显示覆盖情况，不应作为完整证据。
- 快照视图、会话日志和工具结果可能保留被删知识的旧内容；不是隐私清除系统。
- 插件不允许导入外部包，TSX只做语法转译；不提供完整类型检查。沙箱无CPU/内存配额，也非系统沙箱。
- JSON业务导出不是完整备份，没有一键合并导入。完整迁移要停服务复制数据目录。
- 数据schema为v1，没有旧系统数据导入或跨版本自动迁移承诺。升级前备份。

这些项目没有用不可见stub或伪成功按钮冒充完成。当前核心闭环的实际验收项见ACCEPTANCE.md。

- 持续执行不再有固定 Step 上限。重复工具提醒仅检测相同工具与相同参数，并仅在 3/5/8 次提醒，不能保证阻止死循环；不同参数或多工具交替可能绕过提醒。可由用户停止运行。
- 已有项目跨轮目标驱动，未新增 Token/费用/时长预算；上下文缓存与 compaction-basic 核心链路已按固定上游源码移植，Chat Completions、单提供方与可选插件边界见 CACHE-CONTEXT.md。

- 长期记忆、目标推进和交接的新增边界见 PROJECT-CONTINUITY.md；自动记忆内容质量与长任务成本尚无真实提供方验收。

- 检索重排增加一次有界模型调用的延迟与用量；异常时返回 RRF 降级结果。尚未进行真实服务商的排序质量评测。
- 上下文按原文字符计预算，关系只扩展一跳、相关对象取首段；尚无精确 Token 打包、自动查询改写或多轮检索规划。

## 当前设计的剩余边界

- Office 内容阅读不保留全部原始版式、嵌入图表或幻灯片动画，表格显示缓存值、不执行公式。ZIP 条目不写入主机路径。
- 当前是功能实现，不是整套设计逐像素验收完成：组件库部分缩略预览、Bot 全形象状态动画、复杂长文排版仍需细化。
- PDF 文字提取不等于扫描 PDF OCR 或表格结构恢复；图像识别是模型结果，可编辑，并保留原件。
- 音视频播放依赖浏览器支持的编码；自动章节语义切分、说话人分离不在当前通用转写适配中。已支持真实字幕时间、检索与播放跟随。
- 画布整理为确定性网格；分组、连线、锁定与整理撤销已接入，尚无通用跨操作历史栈。并发修改通过 CAS 拒绝覆盖，刷新后继续。
- 用户形象描述可保存；未接生成新头像的图片服务。
- 对象删除会移除资源和直接数据库关系；物理 blob 暂不自动清理，历史引用、快照、日志与备份也不承诺清除。
- 引用反向查询当前扫描资源 citations，未增加大规模专用图索引。

- 缓存链路使用上游固定密度 Token 估计，不是精确 tokenizer。服务商驱逐缓存、冷启动、不同模型及压缩替换仍会影响实际命中率；未承诺 99%。

- 汇报支持按对话请求生成，尚未提供定时汇报调度；界面不显示虚假的定时能力。
